4
▶
  • If you're typing, the queue holds. Your work gets the whole machine.

Check the real number
read it, don't guess it
5
▶
  • A browser opens your usage page and reads the actual percentage and the real reset time.
  • Guessing from local logs misses plan changes and promos. Reading never does.
  • If the number is missing or older than 15 minutes, the queue stops. It refuses to run blind.

  • If a job goes weird, it gets stopped, retried once, then handed to you.
