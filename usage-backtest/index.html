What the math says

Week 1: 100 work / 144 hours = 0.694 work/hour
Week 2: 72 work / 73 hours = 0.986 work/hour
Speed: 0.986 / 0.694 = 1.42×

Both windows exhausted the Claude bucket.
Claude-bucket efficiency: 72 / 100 = 0.72×
Codex usage makes 0.72× an optimistic upper bound, not a penalty included in the score.

To deliver 2× Week 1 in only 73 hours, Week 2 needed a 3.95× hourly work rate. It achieved about 1.42×.

Why the cheaper design did not backtest cheaper

Design premise

Orchestrators work directly. They spawn only when avoided rework exceeds cold-start and coordination cost.

Observed result

More work per hour, but 28% less total useful work per exhausted Claude window.

Failure signal

The gate, compaction policy, or cache estimate did not match real provider usage. The theory was not enforced successfully.

Fleet wins only if:
rework avoided > orchestration + fresh-agent startup + report ingestion + lost cache
